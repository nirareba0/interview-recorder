# 録音テスト

スマホのブラウザで、画面を消しても長い録音が最後まで残るかを確かめるためのページ。

- 録音は端末の中だけにあり、どこにも送らない（サーバーなし・解析なし）
- 10秒ごとに録音のかけらを受け取り、かけらの間が空いたら「途切れ」として記録する
- 止めると、経過時間・ファイルの長さ・途切れ・画面が消えていた時間を出す。結果は文字でコピーできる
- 途中でページが落ちても、端末に残したかけらから取り出せる

開く: https://nirareba0.github.io/interview-recorder/

機械で確かめる: `node test/smoke.mjs`（Chrome に偽のマイクを渡して、8秒録音して結果を読む）
